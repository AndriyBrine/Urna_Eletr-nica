ÍCONES DAS CHAPAS
Coloque aqui uma imagem para cada chapa, com o NÚMERO da chapa como nome do arquivo.
As chapas têm 2 dígitos (01 a 99). Para números de 1 a 9 vale tanto 1.png quanto 01.png:

   01.png    12.jpg    25.svg    (aceita png, jpg, jpeg, webp, gif, svg)

Recomendado: imagem quadrada (ex.: 400x400), fundo claro ou transparente.
Se não houver imagem para uma chapa, a urna mostra o número no lugar do ícone.
Na tela de Administração, a lista de chapas mostra quais já têm ícone.
